# gis-portfolio
Spatial and raster analysis, by utilizing QGIS and open source map for vector layers. The repository also contains detailed usage of all the mathematical equations, and elements used including print maps.

Welcome to my geospatial portfolio. This repository demonstrates cartographic layouts, raster terrain modeling, multi-criteria site suitability, and network routing analyses built in QGIS.

## Featured Projects

1. **[Raster Topography & Terrain Analysis](./1-raster-topography-analysis/)**
   * Digital Elevation Model (DEM) processing, slope derivation, and contour extraction.
2. **[Flood & Earthquake Relief Mapping](./2-flood-earthquake-relief-mapping/)**
   * Vector spatial filtering, hazard zone isolation, and emergency shelter site identification.
3. **[Solar Farm Site Suitability Analysis](./3-solar-farm-site-suitability/)**
   * Multi-Criteria Evaluation (MCE) and weighted raster map algebra combining slope and infrastructure proximity.
4. **[Emergency Hospital Network Routing - Nowshera](./4-nowshera-hospital-routing/)**
   * Shortest-path network analysis calculating distance, travel times, and operational fuel costs (PKR).
